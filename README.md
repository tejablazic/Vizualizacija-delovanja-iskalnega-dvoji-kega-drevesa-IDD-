# Vizualizacija_IDD
### Projektna naloga pri predmetu Programiranje 3

Projekt razvija interaktivni program za vizualizacijo algoritmov vstavljanja, iskanja in brisanja v iskalnem dvojiškem drevesu (IDD). Cilj je ustvariti učinkovito učno orodje, ki uporabnikom omogoča poglobljeno razumevanje delovanja IDD. Program bo omogočal animiran prikaz premikov vozlišč, interaktivne razlage in prilagodljiv vnos podatkov (posamezne vrednosti ali celoten seznam). Ključna prednost v primerjavi z obstoječimi rešitvami bo bolj razumljiva in počasnejša animacija, prilagojena začetnikom, ter možnost množičnega vnosa podatkov.
